# Optional new-ec2 module

This directory is reserved for the optional new EC2 infrastructure module.

Current repository default flow is deploy on existing EC2.

- Existing EC2 deploy flow: scripts/deploy-existing-ec2.sh
- Existing EC2 Nginx config: nginx/existing-ec2/maieuticarh.conf.tftpl
- New EC2 Nginx template: nginx/new-ec2/maieuticarh.conf.tftpl

Do not run terraform apply without human approval.
